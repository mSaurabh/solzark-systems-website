Regulated utility · Data platform

Reporting broke every time the schema changed. Four business units were waiting on numbers they could not trust.

We migrated the legacy operational store to an analytical data store, built an abstraction layer between reporting and the source schema, and designed the row-level security model against existing Active Directory groups.

Healthcare SaaS · QA and search

The vendor's test framework was unsalvageable, and a release serving 500+ organizations was already on the calendar.

We rebuilt it on SerenityJS with the screenplay pattern, wired 400+ tests into Jenkins for nightly runs, and stood up AI-powered search on Bedrock and OpenSearch Serverless behind the same pipeline.

4 mo
Proof of concept to production
$1.8M
Contract extension secured

Tradeoff we named up front: nightly runs need a stable test environment, which was a dependency on their platform team.
